# ಕಥೆಯ ಚೌಕಟ್ಟು ಮತ್ತು ನಿರಂತರತೆಯ ಕೈಪಿಡಿ

ಈ ಕಡತ ನಿರೂಪಕ, ನಿರ್ದೇಶಕ, ಚಿತ್ರ ರಚನೆಕಾರ ಮತ್ತು ಸಂಪಾದಕರ ಬಳಕೆಗೆ. ಕೆಳಗಿನ ಸೂಚನೆಗಳನ್ನು ಕಥೆಯ ನಿರೂಪಣೆಯಾಗಿ ಓದಬೇಡಿ. ದೃಶ್ಯದ ನಿಖರ ಮೂಲಸಾಲುಗಳು ಆಯಾ ಸ್ಕ್ರಿಪ್ಟಿನಲ್ಲಿ ಇವೆ.

## ಯಾರು ಯಾರಿಗೆ ಕಥೆ ಹೇಳುತ್ತಿದ್ದಾರೆ?

| ಚೌಕಟ್ಟು | ಹೇಳುವವರು | ಕೇಳುವವರು | ದೃಶ್ಯಕ್ಕೆ ಮರಳುವ ಗುರುತು |
|---|---|---|---|
| ನೈಮಿಷಾರಣ್ಯದ ಹೊರಚೌಕಟ್ಟು | ಉಗ್ರಶ್ರವ ಸೌತಿ | ಶೌನಕರು ಮತ್ತು ಋಷಿಗಳು | ಪರಿಚಿತ ಅರಣ್ಯದ ಸಭೆ, ಹಿಂದಿನದೇ ಕುಳಿತ ಕ್ರಮ, ಎಲೆಗಳ ಸದ್ದು |
| ಜನಮೇಜಯನ ಸಭೆಯ ಒಳಚೌಕಟ್ಟು | ವೈಶಂಪಾಯನರು | ಜನಮೇಜಯ | ರಾಜನ ಪ್ರಶ್ನೆ ಮತ್ತು ವೈಶಂಪಾಯನರ ಉತ್ತರದ ಜೋಡಿ |
| ಪಾತ್ರ ಹೇಳುವ ಉಪಕಥೆ | ಆ ಸಂದರ್ಭದ ಪಾತ್ರ ಅಥವಾ ಋಷಿ | ಆ ಪಾತ್ರದ ಎದುರಿನ ಶ್ರೋತೃ | ಉಪಕಥೆ ತೆರೆದ ವ್ಯಕ್ತಿಯ ಬಳಿಗೆ ಮರಳಿ ಅದರ ಸಂಬಂಧವನ್ನು ಹೇಳುವುದು |
| ಸಂಪುಟದ ಪರಿಚಯ ಅಥವಾ ಭಾಷ್ಯದ ವಿವರಣೆ | ಸರಣಿಯ ನಿರೂಪಕ | ಇಂದಿನ ವೀಕ್ಷಕ | ಪುಸ್ತಕದ ಪರಿಚಯದ ದೃಶ್ಯಭಾಷೆ; ಇದನ್ನು ಪ್ರಾಚೀನ ಪಾತ್ರದ ಮಾತಾಗಿ ಮಾಡಬೇಡಿ |

ಒಳಕಥೆಗೆ ಹೋಗುವಾಗ ಸ್ಥಳ, ಕಾಲ ಮತ್ತು ಹೇಳುವವರನ್ನು ಮೊದಲು ಸ್ಪಷ್ಟಪಡಿಸಿ. ಕಥೆಯಿಂದ ಕಲಿಯಬೇಕಾದ ಅರ್ಥವನ್ನು ಹೇಳುವ ಮೊದಲು ಆ ಕಥೆಯಲ್ಲಿ ನಿಜವಾಗಿ ಏನಾಯಿತು ಎಂಬುದು ತಿಳಿಯಬೇಕು. ಮೂಲದ ಭವಿಷ್ಯದ ಮುನ್ನೋಟಕ್ಕೆ “ಮುಂದೆ ನಡೆಯಲಿರುವ ಘಟನೆಗಳ ಸಂಕ್ಷಿಪ್ತ ಸೂಚನೆ” ಎಂಬ ಪರಿಚಯ ನೀಡಿ; ಅದನ್ನು ಪ್ರಸ್ತುತ ಕಾಲದ ಘಟನೆಗೆ ಸೇರಿಸಬೇಡಿ.

## ಮೂಲದಲ್ಲಿ ಬೇರ್ಪಡಿಸಬೇಕಾದ ಮೂರು ಪದರಗಳು

ಮೊದಲನೆಯದು ಘಟನೆಯ ಕಥನ. ಎರಡನೆಯದು ಆ ಘಟನೆಯೊಳಗೆ ಪಾತ್ರಗಳು ಹೇಳುವ ವಾದಗಳು, ಪ್ರತಿಜ್ಞೆಗಳು ಮತ್ತು ಪ್ರಾರ್ಥನೆಗಳು. ಮೂರನೆಯದು ಈ ಮುದ್ರಿತ ಆವೃತ್ತಿಯ ಭಾಷ್ಯಕಾರರು ನೀಡುವ ವಿವರಣೆ. ಪಾತ್ರವೊಂದರ ವಾದವನ್ನು ನಿರೂಪಕನ ಸಾರ್ವತ್ರಿಕ ತೀರ್ಪಾಗಿ ಬದಲಿಸಬೇಡಿ. ಭಾಷ್ಯದ ಮಾತಿಗೆ “ಈ ಆವೃತ್ತಿಯ ಭಾಷ್ಯದಲ್ಲಿ…” ಅಥವಾ ಸಂಬಂಧಿಸಿದ ಭಾಷ್ಯಕಾರರ ಹೆಸರಿನಿಂದ ಪ್ರವೇಶ ಕೊಡಿ.

## ತಪ್ಪಿಸಬಾರದ ನಿರಂತರತೆಯ ಅಂಶಗಳು

| ಕಥೆಯ ಭಾಗ | ನಿರೂಪಣೆ ಮತ್ತು ಚಿತ್ರದಲ್ಲಿ ಉಳಿಸಬೇಕಾದ ಸಂಗತಿ |
|---|---|
| ವಿದ್ಯಾಭ್ಯಾಸ | ಪಾತ್ರಗಳ ವಯಸ್ಸು ಮತ್ತು ಹಂತವನ್ನು ಪ್ರತ್ಯೇಕವಾಗಿ ಗುರುತಿಸಿ. ನಂತರ ದೊರಕುವ ಆಯುಧಗಳನ್ನು ಬಾಲ್ಯದ ತರಬೇತಿಗೆ ಹಿಂದಕ್ಕೆ ತರುವಂತಿಲ್ಲ. |
| ಗುರಿಪರೀಕ್ಷೆ | ಈ ಮೂಲದ ಹಕ್ಕಿಯ ಶಿರಸ್ಸಿನ ಪರೀಕ್ಷೆಯನ್ನು ಅನುಸರಿಸಿ. ಪರಿಚಿತ ಬೇರೆ ರೂಪಾಂತರವನ್ನು ಸ್ವಯಂ ಸೇರಿಸಬೇಡಿ. |
| ಅರಗಿನ ಮನೆ | ಸಂಚಿನ ರೂಪಣೆ, ಪಾಂಡವರ ನಿರ್ಧಾರ, ಭೀಮನ ಕ್ರಿಯೆ ಮತ್ತು ಸಂಭವಿಸುವ ಸಾವುಗಳ ಕಾರಣಸಂಬಂಧ ಸ್ಪಷ್ಟವಾಗಿರಲಿ. ಮೃತ ಮಕ್ಕಳನ್ನು ಅಪರಾಧಿಗಳಂತೆ ಚಿತ್ರಿಸಬೇಡಿ. |
| ಶಕುಂತಲೆ | ಈ ಮೂಲದಲ್ಲಿ ಇಲ್ಲದ ಉಂಗುರದ ಕಥೆಯನ್ನು ಸೇರಿಸಬೇಡಿ. ರಾಜಸಭೆಯ ವಾದವನ್ನು ಅದರ ಸ್ವಂತ ಕಾರಣಕ್ರಮದಲ್ಲಿ ಹೇಳಿ. |
| ಇಂದ್ರಪ್ರಸ್ಥ | ನಗರದ ನಿರ್ಮಾಣ ಮತ್ತು ನಂತರ ಮಯನು ನಿರ್ಮಿಸುವ ಸಭೆ ಬೇರೆ ಹಂತಗಳು. ಮಯಸಭೆಯ ಲಕ್ಷಣಗಳು ಅದು ನಿರ್ಮಾಣವಾಗುವ ಮೊದಲು ಕಾಣಬಾರದು. |
| ಅರ್ಜುನನ ಯಾತ್ರೆ | ಉಲೂಪಿ–ಇರಾವಂತ ಮತ್ತು ಚಿತ್ರಾಂಗದೆ–ಬಭ್ರುವಾಹನ ಸಂಬಂಧಗಳನ್ನು ಬೇರ್ಪಡಿಸಿ. ಇಬ್ಬರು ಪುತ್ರರಿಗೆ ಒಂದೇ ವಿನ್ಯಾಸ ಅಥವಾ ಹೆಸರು ಕೊಡಬೇಡಿ. |
| ಸುಭದ್ರೆ | ಹೊರಡುವಾಗ ಮತ್ತು ವಿಪೃಥುವಿನ ಮುಖಾಮುಖಿಯಲ್ಲಿ ಸುಭದ್ರೆ ರಥವನ್ನು ನಡೆಸುತ್ತಾಳೆ. ಅರ್ಜುನನ ಕೈಯಲ್ಲಿ ಬಿಲ್ಲು, ಅವಳ ಕೈಯಲ್ಲಿ ಲಗಾಮು ಎಂಬ ಕ್ರಿಯೆಯ ನಿರಂತರತೆ ಉಳಿಸಿ. |
| ವಿಪೃಥು | ಈ ಆವೃತ್ತಿಯ ನಿಯಂತ್ರಿತ ಆಯುಧಸಂಘರ್ಷ, ಅವನ ಪೂರ್ವಜ್ಞಾನ ಮತ್ತು ನಂತರದ ಆಶೀರ್ವಾದಗಳನ್ನು ಒಂದೇ “ಪರಿಚಯ ಮಾಡಿಕೊಂಡರು” ಎಂಬ ವಾಕ್ಯಕ್ಕೆ ಕುಗ್ಗಿಸಬೇಡಿ. |
| ಖಾಂಡವ | ಗಾಂಡೀವ ಮತ್ತು ಸಂಬಂಧಿಸಿದ ದಿವ್ಯಸಾಮಗ್ರಿಗಳು ದೊರಕುವ ಹಂತವನ್ನು ಗುರುತಿಸಿ. ಅರಣ್ಯದ ಹಿಂದಿನ ಸ್ಥಿತಿ ಮತ್ತು ಅಗ್ನಿಯ ಪರಿಣಾಮದ ನಡುವೆ ಭೌಗೋಳಿಕ ಸಂಬಂಧ ಉಳಿಸಿ. |
| ಅರಣ್ಯದ ಜೀವಿಗಳು | ಮಾಯೆ, ಪಕ್ಷಿಗಳು, ನಾಗರು ಮತ್ತು ಬೆಂಕಿಯ ಪರಿಣಾಮವನ್ನು ಅದರ ಮೂಲಸಂದರ್ಭದಂತೆ ತೋರಿಸಿ. ಜೀವಹಾನಿಯನ್ನು ಕೇವಲ ವಿಜಯದ ಅಲಂಕಾರವಾಗಿ ಮಾಡಬೇಡಿ. |
| ಜರಾಸಂಧ | ಇಲ್ಲಿ ದೊರಕುವ ಅಂತ್ಯದ ವಿವರವನ್ನು ಅನುಸರಿಸಿ. ಈ ಪಠ್ಯದಲ್ಲಿ ಕಾಣದ ಎಲೆ ಹರಿಯುವ ಸೂಚನೆ ಅಥವಾ ಪುನಃ ಜೋಡಣೆಯ ಘಟನೆಯನ್ನು ಸೇರಿಸಬೇಡಿ. |
| ಸಹದೇವ | ಪಾಂಡವ ಸಹದೇವ ಮತ್ತು ಜರಾಸಂಧನ ಪುತ್ರ ಸಹದೇವ ಬೇರೆ ವ್ಯಕ್ತಿಗಳು. ಪರಿಚಯದ ಮೊದಲ ಸಂದರ್ಭದಲ್ಲೇ ಸಂಬಂಧ ತಿಳಿಸಿ. |
| ವಂಶಪಟ್ಟಿಗಳು | ಒಂದೇ ಹೆಸರು ಬೇರೆ ತಲೆಮಾರುಗಳಲ್ಲಿ ಬಂದಾಗ ಪ್ರತಿ ವ್ಯಕ್ತಿಗೆ ಬೇರೆ ಗುರುತು ಬಳಸಿ. ಮರುಕಳಿಸುವ ಹೆಸರನ್ನು ತಪ್ಪೆಂದು ಅಳಿಸಬೇಡಿ. |

## ಪ್ರತಿ ಚಿತ್ರೀಕರಣದ ಮೊದಲು ದಾಖಲಿಸಬೇಕಾದ ಸ್ಥಿತಿ

ದೃಶ್ಯ ಆರಂಭವಾಗುವಾಗ ಪಾತ್ರ ಎಲ್ಲಿದೆ, ಯಾರಿಗೆ ಯಾವ ವಿಷಯ ತಿಳಿದಿದೆ, ಯಾವ ವಾಗ್ದಾನ ಇನ್ನೂ ನೆರವೇರಿಲ್ಲ, ಕೈಯಲ್ಲಿ ಯಾವ ವಸ್ತು ಇದೆ ಮತ್ತು ಉಡುಪಿನ ಯಾವ ಹಂತದಲ್ಲಿದೆ ಎಂಬುದನ್ನು ದಾಖಲಿಸಿ. ದೃಶ್ಯ ಮುಗಿದಾಗ ಬದಲಾಗಿರುವ ಸಂಗತಿಗಳನ್ನು ಮುಂದಿನ ದೃಶ್ಯದ ಆರಂಭಕ್ಕೆ ಸಾಗಿಸಿ. ಮುಖ, ಕೇಶವಿನ್ಯಾಸ ಮತ್ತು ಆಭರಣದ ಒಪ್ಪಿದ reference ಕಡತವನ್ನು ಪ್ರತಿ ಸಂಬಂಧಿತ ಚಿತ್ರಕ್ಕೆ ಜೋಡಿಸಿ.

ಅರಣ್ಯದ ಒಂದೇ ಸಂಭಾಷಣೆಯಲ್ಲಿ ಮಳೆ, ನೆರಳಿನ ದಿಕ್ಕು, ನದಿಯ ನೀರಿನ ಮಟ್ಟ ಮತ್ತು ಹಿನ್ನಲೆಯ ಮರಗಳು ಕಾರಣವಿಲ್ಲದೆ ಬದಲಾಗಬಾರದು. ಕತ್ತರಿಸುವ ಎರಡು ಶಾಟ್‌ಗಳಲ್ಲಿ ವ್ಯಕ್ತಿ ಯಾವ ಕಡೆ ನೋಡುತ್ತಿದ್ದಾನೆ ಎಂಬುದು ಹೊಂದಿಕೆಯಾಗಲಿ. ಬಿಲ್ಲು ಎಳೆಯುವುದು, ರಥ ನಡೆಸುವುದು ಅಥವಾ ವಸ್ತು ಹಸ್ತಾಂತರಿಸುವುದು ಒಂದೇ ಚಿತ್ರದೊಳಗೆ ಹಲವು ವಿರುದ್ಧ ಸ್ಥಿತಿಗಳಾಗಿ ಕಾಣಬಾರದು.

## ಧ್ವನಿಮುದ್ರಣದ ಕ್ರಮ

`Continuous_Recording_Text_Kannada.md`ಯ ಕ್ರಮವನ್ನು ಮೂಲ ಓದುವ ಕ್ರಮವಾಗಿ ಬಳಸಿ. ಶೀರ್ಷಿಕೆ ಮತ್ತು ದೃಶ್ಯ ಗುರುತುಗಳನ್ನು ಧ್ವನಿಯಲ್ಲಿ ಓದಬೇಡಿ. `Recording_and_Edit_Sheet.csv`ಯಲ್ಲಿ ನೈಜ ವಾಚನದ ಅವಧಿ, ಆಯ್ದ take, ಉಚ್ಚಾರಣೆಯ ತಿದ್ದುಪಡಿ ಮತ್ತು ಅಂಗೀಕೃತ ಪಠ್ಯವನ್ನು ದಾಖಲಿಸಿ. ಉಸಿರಾಟ ಮತ್ತು ಅರ್ಥಪೂರ್ಣ ವಿರಾಮಗಳ ನಂತರವೇ ಶಾಟ್‌ಗಳ ಅವಧಿ ನಿರ್ಧರಿಸಿ.

ವಾಚನವನ್ನು ಮೊದಲು ದೃಢಗೊಳಿಸಿ; ಅದರೊಂದಿಗೆ ಹೊಂದಿಸಿ ಉಪಶೀರ್ಷಿಕೆಗಳಿಗೆ ಸಮಯ ನೀಡಿ. ಇನ್ನೂ ಧ್ವನಿಮುದ್ರಿಸದ ಪಠ್ಯಕ್ಕೆ ಕೃತಕ ಸಮಯವನ್ನು ಹಾಕಿ ಸಿದ್ಧ SRT ಎಂದು ಕರೆಯಬೇಡಿ. ಚಿತ್ರ ಸೂಚನೆಯಲ್ಲಿನ ಕನ್ನಡ ಅಕ್ಷರಗಳನ್ನು ಚಿತ್ರಮಾದರಿಯೇ ಬರೆಯುವಂತೆ ಬಿಡದೆ, ಪರಿಶೀಲಿತ ಅಕ್ಷರರೂಪವನ್ನು ಸಂಪಾದನೆಯಲ್ಲಿ ಸೇರಿಸಿ.

## ಅಂತಿಮ ಭಾಗದ ಮಿತಿ

ನೀಡಿದ ಮೂಲದಲ್ಲಿ ಆದಿಪರ್ವದ 237 ಅಧ್ಯಾಯಗಳು ಮತ್ತು ಸಭಾಪರ್ವದ ಮೊದಲ 24 ಅಧ್ಯಾಯಗಳು ದೊರಕಿವೆ. ಮುಖ್ಯಕಥೆ ಜರಾಸಂಧನ ಅಂತ್ಯ, ರಾಜರ ಬಿಡುಗಡೆ ಮತ್ತು ಇಂದ್ರಪ್ರಸ್ಥಕ್ಕೆ ಮರಳುವವರೆಗೆ ಬಂದಿದೆ. ಉಳಿದ ಮಹಾಭಾರತಕ್ಕೆ ಮುಂದಿನ ಮೂಲ ಸಂಪುಟಗಳು ಅಗತ್ಯ. ಈ ಮಿತಿಯನ್ನು ಸರಣಿಯ ಪರಿಚಯ ಮತ್ತು ಸಂಪುಟದ ಕೊನೆಯ ಟಿಪ್ಪಣಿಯಲ್ಲಿ ಸ್ಪಷ್ಟಪಡಿಸಿ.
