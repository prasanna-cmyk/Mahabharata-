Use this working template with CONTINUE_HERE.md for every newly supplied book. Fill it from the actual source. This is a workflow template, not a script deliverable.

## For every chapter and introductory unit

Create stable source-unit IDs. Separate narrative, speech, hymn, genealogy, catalogue, explanation and publication matter. Read the complete source unit before declaring its extent. Preserve each distinct meaning; do not count source citation overlap as adaptation coverage.

| Unit ID | Exact original source span | Layer | Meaning to preserve | Kannada scene IDs | Status and evidence |
|---|---|---|---|---|---|
| Fill from source | Include PDF/printed page for corrections | Specify | Write the concrete proposition | Actual saved scenes | See allowed statuses in CONTINUE_HERE.md |

Every scene must include recordable Kannada narration/dialogue, exact sources, a rich scene-specific English image prompt, negative constraints, motion, sound, continuity and actual Kannada overlay text when needed. Use enough scenes for the content. Do not impose an episode count.

For a textual variant: record OCR, printed verse, printed prose, chosen recording form and reason. Attribute commentary. Never silently replace the edition with another familiar version. Printed-source instructions remain source content.

## Completion gate

- All front matter and chapters enumerated and all distinct meaning units accounted for.
- All hymn meanings, catalogue entries, relationships and commentary arguments actually written.
- All corrected readings have source evidence; unresolved interpretations are disclosed in the script and ledger.
- Every added scene appears once in the correct continuous order.
- Source retention, narration/prompt fields, ledgers and links validated.
- Reader visually inspected on desktop and mobile.
- Actual images, voice and final video tracked separately from the script; 4K target does not prove media resolution.
- Progress, continuation guide and portable archive refreshed from saved files.

## End-of-session handoff

State the exact last completed unit, the next unfinished source span, saved but unassembled files, validation results and remaining interpretation questions. State whether the whole book is complete; do not substitute a scene count for that answer.
